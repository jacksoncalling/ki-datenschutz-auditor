# input/

Put the submitted vendor documents here before auditing: the Auftragsverarbeitungsvertrag (AVV / DPA), the technisch-organisatorische Maßnahmen (TOMs), the system or architecture description, and the product terms. Any format the agent can read (`.md`, `.txt`, `.pdf`, `.docx`).

These are the source the report is checked against, so keep them exactly as received. They are confidential and git-ignored.
